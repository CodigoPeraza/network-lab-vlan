# Archivo de Packet Tracer

Construye la topología descrita en `docs/topology.md`, aplica las configuraciones de `configs/` y guarda el archivo aquí como:

```text
topology/network-lab-vlan.pkt
```

El archivo `.pkt` es binario y debe exportarse manualmente desde Cisco Packet Tracer. Una vez guardado, agrégalo al repositorio y haz push.
